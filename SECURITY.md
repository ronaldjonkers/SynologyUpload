# Security policy

## Supported versions

Only the [latest release](https://github.com/ronaldjonkers/SynologyUpload/releases/latest) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository
([direct link](https://github.com/ronaldjonkers/SynologyUpload/security/advisories/new)).

Please include:

- the Upload Portal version and DSM version
- a description of the issue and its impact
- steps to reproduce

You can expect a first response within a few days. Once a fix is released, you will be credited in the changelog unless you prefer otherwise.

## Scope

In scope: the upload server, the DSM admin app and CGI bridge, and the package scripts.
Out of scope: vulnerabilities in DSM itself, Node.js or third-party reverse proxies.
